Notation — who did it

One Browser lane (human plus engine). Every step carries who ran it; human steps start at Browser. The bundle never calls ERP API directly: Bundle to Browser fetch, Browser to ERP API HTTPS with cookie, ERP API to Browser, Browser to Bundle. No push channel exists; the browser polls and refetches.

steps in order
1Numbered badge per step restarts each diagram; step 1 is always the handoff from the previous diagram.
2HUMAN marks the only human clicks, types, and submits; everything else is automatic.
3BROWSER runs navigation, downloads, cookie attach, redirects, and paint. PORTAL runs bundle JavaScript: fetch, routing, render, local cache.
4ERP API runs guard, modules, domain, and database work. WORKER runs the outbox relay: event relay, cache delete, mail.
5DNS and CDN resolve and deliver static files; IDP is the external identity provider for SSO (Single Sign-On) only.
