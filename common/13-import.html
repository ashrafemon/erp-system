Flow

sequence
1POST /import/uploads → CreateImportUploadUseCase: FileStoragePort.createPresignedUpload + storage_objects IMPORT_SOURCE. Browser PUTs to S3.
2POST /import/jobs @Idempotent() → CreateImportJobUseCase [TX]: snapshot descriptor; BullMQ parse stage.
3Parse: ParseImportJobUseCase + ImportFileParser (xlsx/CSV, header/alias) → ColumnMapping → GET preview. PATCH /:id/mapping confirms.
4Validate: ValidateImportJobUseCase chunks (500): structural + handler.validateBatch → VALID/INVALID/DUPLICATE.
5Execute: POST /:id/execute → StageLock.acquire (locking) → claimForExecution (200) → re-validate (staleness) → handler.executeBatch → applyExecutionResults → recount → COMPLETED(+ERRORS)/FAILED + outbox; error report → Storage.
6Reconciliation resumes orphaned stages via lock takeover; purges expired storage. Registered: vendor, purchase-order (grouped by poReference → one DRAFT PO).
