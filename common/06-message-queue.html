06 · Message Queue — One Port, Broker by Param

Role: infrastructure-agnostic async transport after an outbox row is ready. One public port; the envelope param picks the broker. Knows exchanges/topics/queues; knows nothing about domain semantics.

Contents · Ports · Flow · Sequence · Layout · Config · Rules

Public ports

Inject MessageQueuePort to send across processes. One method. The broker field on the envelope picks rabbitmq, kafka, or sqs.

methods
publish(envelope) → voidRoutes on envelope.broker inside messaging. Unconfigured broker throws, the outbox retries to DLQ (Dead-Letter Queue).
envelope: { eventType, aggregateType, aggregateId, payload, headers, broker? }broker defaults to rabbitmq. Headers carry event-id, correlation, causation, tenant.
// normally called by the outbox publisher, not business code
await this.messageQueue.publish({ eventType: 'OrderCreated', aggregateType: 'SalesOrder',
  aggregateId: order.id, payload: orderPayload, headers: traceHeaders, occurredAt: new Date(), broker: 'rabbitmq' });

Flow

sequence
1OutboxPublisher.claimBatch, MessageQueuePort.publish(envelope with broker param)
2rabbitmq: topic exchange erp.events, routingKey = eventType, persistent, 10s timeout
3kafka: topic = eventType
4sqs: configured queue
5Consumer side in business (NOT platform): @RabbitSubscribe / @KafkaEvent / @SqsMessageHandler listener, then Inbox.receive, application use case, Inbox.complete, broker ACK (acknowledgement)

Config via messaging.config

env
RABBITMQ_URL
RABBITMQ_EXCHANGEerp.events
KAFKA_BROKERS (optional, adapter disabled when empty)
SQS_URL, SQS_REGION (optional, adapter disabled when empty)
MESSAGE_QUEUE_PUBLISH_TIMEOUT_MS=10000 (adapter-bounded; unresponsive broker keeps PENDING plus backoff, never blocks the transaction)

Rules

rules
Business never imports amqplib, kafkajs, sqs libs (ESLint).
At-least-once; consumers dedupe via Inbox + stable event-id.
Same envelope on every broker; tenant/correlation headers preserved. Unconfigured broker target throws, outbox retries to DLQ (Dead-Letter Queue).
