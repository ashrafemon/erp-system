20 · Storage — S3 Objects

Role: private up/download/metadata/presigned URLs. Only consumer: platform/import. PUT only, never public.

Contents · Ports · Flow · Sequence · Layout · Config · Rules

Public port

Inject FileStoragePort — private visibility always.

methods
upload({key,body,contentType?,metadata?}) → {key,size}disk.put private.
download(key) / delete(key) / getMetadata(key)Delegate; null when missing.
getPresignedUrl(key, ttl?) → stringTemporary URL; never disk.url() public fallback.
createPresignedUpload({key,expiresIn, maxBytes?, contentTypes?})PUT presign + expiresAt; caps advisory — enforced later by import.

Flow

sequence
1Import CreateImportUploadUseCase → createPresignedUpload + storage_objects IMPORT_SOURCE. Browser PUTs straight to S3.
2upload: disk.put private → size=body.length. download/delete/getMetadata delegate.
3createPresignedUpload: PUT presign, expiresAt=now+ttl; maxBytes/contentTypes advisory.
4Import enforces later via getMetadata size + DTO allowlist. Keys tenant-scoped: imports/<tenant>/<entity>/<uuid>.
