16 · Notification — Email/SMS/Push Pipeline

Role: the one shared way to reach a human outside the app. EVENT path (outbox class → dedup → request) or HTTP POST; per-recipient x channel messages claimed, rendered, sent, receipted, finalised.

Flow

sequence
1Onboarding: NOTIFICATION_HANDLERS[] (type,channels,priority,eventName?,ownerModule) + configureNotifications validates; dup type throws.
2EVENT: notification-event.dispatcher onAny → findByEventName → dedupKey=type:eventId → SendNotificationUseCase. HTTP: POST /notifications (SYNC→200, ASYNC→202).
3Send phases 1-3: dedup findByDedupKey; createRequest PENDING; resolveRecipients/Model; expand pairs; gate preference opt-out then suppression block-list else PENDING; mode = pending≤syncThreshold & HIGH ? SYNC : ASYNC; attachMessages; SYNC in-process else dispatchChunks.
4Worker phase 5 (concurrency 5): markRunning; claim WHERE PENDING→RENDERING; resolveActive template tenant-first (missing → markFailed); TemplateRenderer {{var}}; provider.send; markSent + progress.
5Phase 6 ApplyDeliveryEventUseCase: parseDeliveryReceipt → applyDeliveryStatus only forward; BOUNCED writes suppression. Phase 7 finalise + outbox Completed. Phase 8 reconcile every 5m.
