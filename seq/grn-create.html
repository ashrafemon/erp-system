Goods Receipt Note — Create

Role: Create against an approved purchase order: PO reference through the public contract, accumulating lines, outbox in-transaction.

Contents · Flow · Sequence · Sequence — async

Flow

steps in order
1Client posts CreateGrnDto; controller calls CreateGrnUseCase in one transaction.
2PurchaseOrderPort resolves the source order through PurchaseOrderForGrnFacade; missing or unsuitable orders fail fast.
3GrnFactory.create enforces invariants; the aggregate instantiates and accumulates lines, raising GrnCreated.
4Duplicate number pre-check returns 409 when taken; command repository saves through the mapper on TransactionHost.
5Aggregate pullEvents drains into the integration port; OutboxAdapter appends through OutboxWriterPort in the same transaction.
6COMMIT persists state plus event atomically; controller answers with the new id.
