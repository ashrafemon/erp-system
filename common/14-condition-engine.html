Flow

sequence
1Recurring handler parses stored JSON via GenerationConditionParser (null → pass-through decision by caller).
2Per clause: registry.resolve(field) — split '.', getEntry(prefix); missing → throw 'No FieldResolver registered'.
3matches: eq/neq strict ===/!==; gt/gte/lt/lte compare (number-number, string-string, else false); in/notIn includes.
4Combine AND/OR → {passed, evaluatedValues} for audit. Non-trivial condition with zero resolvers throws until owner registers every prefix.
