Layer responsibilities plus dependency direction

calls point inward
1HTTP Controller calls the use case, which builds through the Domain aggregate plus Factory.
2Use case reaches outbound ports plus the integration port; the integration port forwards through OutboxAdapter to the platform OutboxWriterPort.
3Command path persists through the command repository port on TransactionHost inside the @Transactional boundary.
4Query path skips domain and outbox entirely through the query port on PrismaReadPort (replica).
5Cross-module reads run consumer adapter (own module adapters) to producer facade (producer facades).
6OutboxScheduler cron claims with SKIP LOCKED, OutboxPublisher fans out through MessageRoutingPolicy to RabbitMQ, Kafka, SQS, plus in-process re-dispatch.
rules, enforced by eslint plus lint:check
Domain stays clean.zero @nestjs, zero @platform, zero @infrastructure imports.
business never reaches infrastructurenever another module internals (domain, usecases, queries, integrations, facades, infrastructure). Only another module public or outbound-ports contract.
platform never reaches businessplatform owns its OutboxEvent contract; business DomainEvent satisfies it structurally; rehydrators bridge as a delegate at bootstrap.
raw clients stay fencedprisma, amqplib, kafkajs, ioredis and schedule live in infrastructure, config, bootstrap, or platform only.
listener carve-outintegrations/listeners may use subscribe decorators but must delegate to use cases, no inline logic.
ports are abstract classeseach port is its own DI token, bound with useClass or useExisting; PlatformModule is never global, business modules import it explicitly.

Domain — aggregate is the sole mutation path

patterns
Value objectextends ValueObject, private constructor, static create normalizes; validation lives in the sibling invariants file.
Aggregateextends AggregateRoot, private props and constructor, instantiate reserved for factory and mapper; mutation methods enforce then addEvent; status machines live here.
Factorysole sanctioned build path: enforce invariants, instantiate with generated id, raise the initial event; side-effect-imports all invariant and policy files.
Events plus rehydratorsDomainEvent carries eventId, occurredAt, version, correlation and causation; every persisted event registers a rehydrator rebuilding value objects.
Policiesregistry rules reading external data, never own state; rule classes never cross-import aggregates.
Shared primitivesAggregateRoot with version plus event drain, Entity, ValueObject, DomainEvent, Money minor-units math, invariant, policy, and domain-event registries.

Application — command versus query

command use case, exact 6-step flow
One @Injectable class plus @Transactional boundary per command; orchestrates module-local ports and cross-module outbound ports; never publishes to brokers directly.
@Injectable()
export class CreateXUseCase {
  constructor(
    private readonly xs: XCommandRepository,
    private readonly integration: XIntegrationPort,
    private readonly companyConfig: CompanyConfigPort,
  ) {}
  @Transactional()
  async execute(input: CreateXRequest): Promise<XId> {
    const company = await this.companyConfig.getCompanyConfig(); // 1 context
    const x = XFactory.create({ ... });                          // 2 build + invariants
    const dup = await this.xs.findByUniq(x.uniq);                // 3 pre-check
    if (dup) throw new ConflictException(...);
    await this.xs.save(x);                                       // 4 persist, same tx
    for (const ev of x.pullEvents())                             // 5 drain
      await this.integration.send(ev, x.id.toString());          //   outbox via port
    return x.id;                                                 // 6 return id
  }
}
query plus ports
Queries stay read-only.Skip aggregate and outbox; query port on the replica returns plain records; no aggregate hydration.
Controllers call use cases directly.No inbound-port or mediator layer.
Module-local outbound port.Declare the abstract port locally, implement the adapter over the platform token, bind with useExisting; domain and use cases never import platform.
Integration port.Abstract send(event, id); single OutboxAdapter forwards to OutboxWriterPort.append inside the same transaction.
Listeners.One class per transport per event with subscribe decorators; every handler delegates to a use case or facade.

Public contract — cross-module reads

producer and consumer
Producer owns public.Plain reference contract plus abstract port, re-exported from public index; facade implements it by delegating to its own query use case; module exports the port.
Consumer owns the outbound port.Typed against the producer contract shape; bound in module adapters that inject the producer public port; consumer imports the producer module only to resolve the provider.
Direct injection.Use-case constructors take the outbound-port token; Nest resolves the bound adapter at instantiation.
Live wiring.PurchaseOrder reads Product and Vendor; GoodReceiptNote reads PurchaseOrder. Only ACTIVE products are purchasable and only ACTIVE vendors orderable; write triggers travel by RabbitMQ listener instead.

Infrastructure — persistence plus adapters stay with the module

patterns
Mapper.toDomain through instantiate, toRow, toRecord; Money through decimal and JSON helpers.
Command repository.Injects TransactionHost so the aggregate change and the outbox row commit atomically inside the use-case boundary.
Query repository.Injects PrismaReadPort on the replica, falling back to the write pool.
Platform adapters.Outbox, company-config, and numbering adapters; prefer platform NumberingPort for new document numbers.
Module adapters.Consumer side only, injecting producer public ports.

Presentation — thin controller, Zod DTOs, device-aware responses

patterns
Requests.One DTO per file with Zod schema plus exported schema; global validation pipe maps failures to 422.
Responses.Per-endpoint web (full) plus mobile (minimal) DTOs selected by x-device-type header.
Envelope.Controller returns data plus message; the global interceptor wraps status, statusCode, data, message; the filter maps HTTP errors. Controllers never read RequestContext; the use case resolves tenant and actor.

Outbox, events, messaging

what the use case triggers
1Use case appends each drained domain event through integration port to OutboxWriterPort, same database transaction as the aggregate write, tenant plus trace headers stamped from RequestContext.
2OutboxScheduler polls and OutboxPublisher claims with SKIP LOCKED (claimedAt lease, attempts plus nextRetryAt backoff), publishes per-aggregate FIFO, re-dispatches in process with stable envelope identities.
3Routing policy fans out per event type across RabbitMQ topic exchange, Kafka, and SQS; adding a listener means adding its target.
4Statuses run PENDING to PUBLISHING to PUBLISHED, FAILED, or DEAD_LETTER, with lease-expiry reconciliation plus hourly cleanup; delivery is at-least-once and consumers dedupe on the stable event id.

Creating a new business module

build order, templates live in the business-module guide
1Schema first: context prisma file plus hand-written migration SQL, then prisma generate.
2Domain leaf to root: types, enums, value objects plus ids, invariants, events plus registries, policies, aggregate, factory with side-effect imports.
3Domain command-repository port plus application query port.
4Use cases: command 6-step flow, queries through the query port.
5Infrastructure: mapper, command repo, query repo, platform adapters plus module-local ports.
6Public contract, port, and index when others read you, plus a facade delegating to a query use case.
7Presentation: request DTOs, web and mobile response DTOs, thin controller.
8Listeners only when consuming broker events, plus routing entries for new Kafka or SQS targets.
9Module file bindings as above; wire into the context module; register the module path for lint.
10Bridged opt-ins: one row per feature table in the bootstrap configurators.
11Tests plus docs: aggregate spec plus use-case spec on fakes; typecheck, lint, unit tests, DI docs.
acceptance
Clean domain.Zero framework imports; aggregate-only mutation through the factory.
Correct paths.Commands transactional with repo plus outbox append and no direct publish; reads on the query port plus replica; every persisted event carries a rehydrator.
Clean boundaries.Cross-module traffic only through public plus outbound ports; lint, types, and unit tests green.
known gaps, do not copy blindly
Business tables not yet tenant-scoped.Single shared instance by design today; platform tables already are.
