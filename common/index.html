Wiring rule

rule
Ports stay only at module boundaries (public API). Inside a module, use cases inject the concrete Prisma repository / adapter class directly. No *RepositoryPort plus useExisting ceremony. One port, one Service: every public port is implemented by exactly one Service class, which delegates to use cases. Every async operation is its own use-case class; sync pure helpers stay on the service.
Direction: business consumes ports, platform wraps infra.Business modules inject platform ports only and never import infra clients. Each common service wraps its infra client once (Redis, Prisma TransactionHost, broker SDKs), so no module ever rewrites infra access.
No controllers on common services.All 21 ports resolve through DI to services (business module imports PlatformModule, use case injects the port). HTTP lives only in business controllers; the only HTTP touchpoint here is the @Idempotent() decorator reused on business routes.
