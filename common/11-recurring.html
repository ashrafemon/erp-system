Flow

sequence
1POST /recurring-templates → CreateRecurringTemplateUseCase @Transactional: templates row + SchedulerPort.schedule({jobType:'Recurring',aggregateType:'RecurringTemplate',aggregateId}) ONE tx.
2Ticker → ScheduledJobProcessor → 'Recurring' handler (jobId!=null). Tenant-mismatch throw.
3claim execution (templateId,triggerKey=YYYY-MM-DD) insert-as-claim; collision → skip (sweeper heals). Not ACTIVE → skip(TemplateNotActive).
4ConditionEvaluator.evaluate(generationCondition); fail → skip(ConditionNotMet) + reschedule.
5Pass → OutboxWriterPort.append(RecurringOccurrenceRequested, 'RecurringTemplate', id) + reschedule via RecurrenceEngine.nextRunDate; past endDate → COMPLETED + cancelByAggregate.
6Outbox → Rabbit erp.events → business creates doc (NumberingPort INV-/PO-) → complete/fail. EVENT path: no scheduled_jobs row; dispatcher matches ACTIVE templates by eventName, jobId=null.
